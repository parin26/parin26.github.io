# Parin Shah — Portfolio

Personal portfolio site: AI security, adversarial ML, GenAI red teaming, and edge inference optimization.

**Live:** https://parin2605.github.io/

## What's here

| Path | Purpose |
|---|---|
| `index.html` | The entire site — one self-contained static page, no build step, no dependencies |
| `resume/` | Downloadable résumés linked from the site |
| `.nojekyll` | Tells GitHub Pages to serve files as-is instead of running Jekyll |

## Local preview

No toolchain required — open `index.html` in a browser, or:

```bash
python -m http.server 8000
```

## Deploying

Pushing to the default branch publishes automatically once GitHub Pages is enabled
(Settings → Pages → Source: *Deploy from a branch* → `main` / `root`).
