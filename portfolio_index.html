Most AI security work stops at a findings report. The reason I get hired for both halves is that the offensive pass is wired into the control that ships afterwards.

Selected engagement — customer accelerator hardware

6 months
Objective
Establish whether an image-classification model deployed on a silicon partner’s own accelerator was exposed to extraction in real operating conditions, rather than in a lab replica.
Method
Executed model extraction against the deployed classifier on the customer’s hardware, running the same harness used across the edge testbed above.
Measured
Inference time, model accuracy and memory footprint — captured before and after the attack, so the cost was expressed in the numbers the customer already tracked.
Outcome
A measured robustness baseline on production silicon instead of a qualitative risk rating, and a repeatable procedure the team could re-run against future model versions.

Independent builds

Built outside work, mostly because I wanted the thing to exist. They are where I own the whole stack — data, model, API, interface, deployment — and where security instincts from the day job become design constraints instead of review comments.

FinMitra

NODE.JS · EXPRESS · GEMINI 2.5 FLASH · DOCKER · AWS EC2

An Indian personal finance app answering the questions banks make deliberately hard: which card actually pays off for your spending, which salary account is worth switching to, how an FD compares to a debt fund after tax.

Six modes over one grounded-generation backend. Source attribution is extracted from the model's own grounding metadata and disclaimers enforced server-side — after early testing surfaced misattributed bank rates and invented card variants.

InsureCompare

PYTHON · FASTAPI · HTMX/JINJA · PLUGGABLE LLM

One search across health, car, bike and term life insurance, so you enter your details and add-ons once instead of filling the same form on nine insurer websites.

A deterministic scoring engine drives the ranking so it stays auditable; the LLM only writes explanations. A crawler feeds public insurer pages through a human review queue, and premiums show as labelled estimates that link out for a binding quote.

Agentic Job Application System

NODE.JS · GMAIL OAUTH · TELEGRAM HITL · GEMINI

Watches job-alert email, parses each description, tailors a resume against it, and queues the result for approval.

Designed around the constraint rather than past it: nothing auto-submits, every application clears a Telegram approval step, and throughput is capped. Automating the drafting is the useful part; automating the submission is what gets accounts banned.

Product Comparison Engine

PYTHON MICROSERVICES · DOCKER COMPOSE · MULTI-PROVIDER LLM

Takes a plain-language requirement — a budget, a use case — and returns specs, trade-offs and prices across retailers, with the strongest pick surfaced rather than buried in a table.

The LLM layer is provider-agnostic across Claude, OpenAI and Gemini, backed by a deterministic fallback ranker and an intent-synonym layer so the service still answers when a provider is down.

Lyric-Aware Video Pipeline

FASTAPI · REMOTION/REACT · GEMINI · CONDA

Song name in, a 30–60 second reel and a caption explaining what the lyric actually means out — built to make a specific kind of writing publishable at a regular cadence.

Segment selection returns three ranked candidates instead of one guess, a separate visual-direction microservice runs alongside the renderer, and Devanagari source text is spliced rather than regenerated, because models quietly corrupt scripts they are weak in.

Edge Adversarial Testbed

TENSORFLOW · TFLITE · RASPBERRY PI · JETSON NANO · KRIA KV260 · ESP32

The hardware bench behind two of the publications: one CNN, five deployment targets, one consistent attack harness, to find out whether moving a model to the edge changes its attack surface.

It does not, materially — which is the finding. Extraction and evasion transferred across CPU, GPU, FPGA and microcontroller targets with performance intact.
